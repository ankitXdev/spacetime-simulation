## Basic Maven Commands

| Command | What it does |
|---|---|
| `mvn clean` | Deletes the `target` folder/build |
| `mvn compile` | Compiles your Java code |
| `mvn test` | Runs tests |
| `mvn package` | Builds a JAR |
| `mvn clean package` | Cleans the project and builds a JAR |
| `mvn install` | Builds and puts the JAR in your local Maven repository |
| `mvn verify` | Runs checks and verifies the project |
| `mvn validate` | Checks whether the Maven project is valid |
